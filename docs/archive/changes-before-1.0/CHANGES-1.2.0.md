# Изменения 1.2.0

- Переключатель «Каждое слово отдельно / Целая фраза». Отдельные команды выполняются по стабильным промежуточным словам, повторы окончательного текста подавляются.
- Стабилизация слов 50–500 мс, пауза окончания фразы 120–1500 мс. Блок аудио уменьшен до 1024 отсчётов.
- Для каждой фразы: короткое нажатие 65 мс либо удержание 20–10000 мс. Можно назначать несколько фраз одной клавише.
- Очередь одной клавиши, независимые удержания разных клавиш, немедленное отпускание и отмена очереди при остановке.
- Выбор Vosk RU/EN и T-one Streaming RU через sherpa-onnx; локальная загрузка дополнительной модели из интерфейса.
- Компактные столбцы действия и длительности; индикаторы удерживаемых клавиш; журнал фактической длительности.
- Старые настройки сохраняются; новые поля получают совместимые значения. Языки переключаются отдельно.
- Автотесты разделения слов, изменений гипотез, длительности, очереди, отмены и совместимости; интеграционный прогон обеих моделей и реального ввода в собственное окно.

На синтезированном тестовом слове ожидание Vosk после конца слова уменьшилось примерно с 1,37 с до 0,29 с. Это не гарантия для любой записи. Методика, ограничения и альтернативы — `MODELS.md`; результат прогона — `QA-1.2-RESULTS.json`; ручные сценарии — `TESTS.md`.
