# Изменения Voice Keys 1.5.0

- Журнал → команда: слово, которое не распозналось, назначается команде прямо из журнала и работает сразу, без остановки прослушивания. Режим слов теперь показывает в журнале и текст без единой команды.
- Модификаторы Ctrl / Shift / Alt у каждой команды; кнопка ⌨ принимает сочетание. Команды с разными наборами модификаторов не перекрываются; общие модификаторы отпускаются вместе с последней командой.
- Кнопки мыши (левая, правая, средняя, боковые) и колесо (вверх, вниз, влево, вправо) как цели команд, включая удержание кнопок и Ctrl+колесо. Прослушивание по удержанию по-прежнему только на клавише клавиатуры.
- Значок в трее с состоянием, меню (окно, включить/остановить, профиль, звук, выход), сворачивание в трей при закрытии окна (можно отключить).
- Звуковой сигнал при распознавании команды и при нажатии, громкость, отдельные включатели.
- Экспорт и импорт профилей в файл `.json`.
- Тёмная тема (светлая, тёмная, как в Windows). Тёмные стили генерируются из светлых скриптом.
- Диагностика задержки: после появления слова, от начала речи, среднее; значения в логе.
- Оверлей всегда на основном мониторе Windows.
- Исправлена ошибка при выходе: закрытие уже закрытого окна оверлея.
- 83 автоматические проверки; интеграционный прогон — `QA-1.5-RESULTS.json`.
