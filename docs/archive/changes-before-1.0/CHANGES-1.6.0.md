# Изменения Voice Keys 1.6.0

- Новая модель **GigaAM v3 · RU** (Sber, MIT): список «Модель» → «Загрузить» (около 163 МБ). Работает в режимах слов и фраз, в замере образцов и при записи произношения голосом.
- Для офлайновой модели добавлено псевдопотоковое распознавание: звук реплики копится, текст обновляется каждые ~120 мс, окончание реплики определяется по паузе. Перед речью хранится только 0,3 с звука, реплика не длиннее 12 с.
- В тесте на синтетических словах GigaAM распознала все слова, а Vosk Small — нет. Команды срабатывали примерно через 20 мс после конца слова.
- Загрузчик моделей общий для T-one и GigaAM (`node scripts/setup-sherpa.js gigaam`).
- 86 автоматических проверок.
