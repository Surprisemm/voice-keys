# Изменения Voice Keys 1.4.0

- Шапка с состоянием («Выключено» / «Слушаю») и кнопкой «Включить» / «Остановить» закреплена вверху окна и не прокручивается вместе со страницей.
- Одна клавиша — несколько слов. В поле «Что сказать» можно написать варианты через запятую: `ку, кью, пэ`. Любой из них нажмёт клавишу. Разные строки по-прежнему могут использовать одну клавишу.
- Запись произношения голосом: кнопка 🎙 в строке. Приложение просит сказать слово три раза и добавляет в строку то, что услышала модель, включая ошибки распознавания. Клавиши при записи не нажимаются.
- Варианты, записанные голосом, срабатывают без проверки уверенности Vosk: модель обычно сомневается именно в ошибочных вариантах. Вручную набранные слова проверяются как раньше.
- Длительность удержания больше не занимает отдельный столбец. Поле «мс» появляется рядом с действием только в строках «Удержать»; таблица не меняет ширину.
- Значения по умолчанию: прослушивание «Постоянно», команды «Каждое слово отдельно», оверлей со сдвигом Y 100 px (прежние 40). Уже сохранённые настройки не меняются.
- Старые настройки читаются без изменений. 67 автоматических проверок.
