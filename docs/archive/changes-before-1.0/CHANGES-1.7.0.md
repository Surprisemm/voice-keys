# Изменения Voice Keys 1.7.0

Порядок блоков окна, сверху вниз:

1. Основные настройки: микрофон, когда слушать (клавиша удержания видна только в режиме «При удержании»), команды — слова или фразы.
2. Профили: выбор, создание, имя, удаление, экспорт, импорт.
3. Команды (с кнопкой «+ Добавить» внутри блока) и справа проверка.
4. Раздел «Настройки»: распознавание (язык, модель, уверенность, стабилизация, пауза фразы), очередь и оверлей, звук, вид и трей, образцы голоса и замер скорости. Свой «Сохранить» в заголовке раздела.
5. Журнал.

Поведение и настройки не менялись.

## Сборка

- Папка `release/`: `win-unpacked/Voice Keys.exe` и один файл `Voice-Keys-1.7.0-portable.exe` (electron-builder). Внутри Vosk RU/EN и GigaAM v3; T-one скачивается.
- В собранной версии данные лежат рядом с exe в `VoiceKeys-data`, скачанные модели — в `VoiceKeys-data/models`.
- Прогон собранной версии: `QA-1.7-RELEASE.json`.
