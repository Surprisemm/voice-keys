# Проверка Voice Keys

Закройте старую версию и откройте `start.bat`. Начните с режима «Только показать», русского языка и Vosk. Прежние назначения находятся в профиле «Основной».

| Тест | Действие | Ожидаемый результат |
|---|---|---|
| T01. Миллисекунды | У строки выбрать «Нажать», затем «Удержать». | Для нажатия поля мс нет. Для удержания справа от действия появляется поле «мс»; ширина таблицы и других строк не меняется. В экранном журнале обычное нажатие тоже без мс. |
| T02. Три повтора | Режим «Каждое слово отдельно», сказать «первый первый первый». | Если модель распознала три слова — три Q, без повтора после окончательного текста. |
| T03. Смешанная очередь | Сказать «первый первый первый второй второй второй». | Q Q Q W W W в таком порядке. Для более заметной очереди можно временно увеличить интервал до 300 мс. |
| T04. Исправление текста | Продолжать говорить команды, когда модель меняет начало распознанной строки. | Нет сообщения о блокировке из-за изменения слов; новые распознанные команды продолжают выполняться. |
| T05. Разные действия Q | «удар» → Q / Нажать, «хэви» → Q / Удержать / 1000. | При верном распознавании первое — короткое нажатие, второе — удержание. После него повтор Q выполняется с отпусканием между действиями. |
| T06. Остановка | Удержание 5000 мс, ещё несколько команд в очереди; нажать «Остановить» или Ctrl+Shift+F8. | Активные клавиши отпущены, ожидающие команды отменены. |
| T07. Оверлей | «Очередь и оверлей» → «Показать пример». | Три плитки: ожидающие яркие, выполненные имеют прозрачность 50%, затем исчезают. Демонстрация не нажимает клавиши. |
| T08. Ориентация | Выбрать вертикальное/горизонтальное направление, положение, размер и время, сохранить и показать пример. | Настройки применились. Пустая полоса скрыта, мышь проходит сквозь неё. В игре проверить отдельно в режиме окна без рамки. |
| T09. Профили | Создать Dota, назначить команды; создать Deadlock и другие команды. Переключать профили. | Каждая таблица восстанавливается независимо. Пустой новый профиль допустим. Копирование создаёт независимые назначения. |
| T10. Быстрое переключение | При включённом прослушивании выбрать другой профиль. | Ввод и очередь останавливаются. Таблица и настройки распознавания меняются; нужно включить прослушивание снова. |
| T11. Имена и сохранение | Переименовать профиль, перезапустить, удалить ненужный профиль с подтверждением. | Имена и команды сохранены. Последний профиль удалить нельзя. Записи при удалении профиля остаются в папке данных. |
| T12. Запись | Остановить команды, открыть «Образцы голоса и замер скорости», ввести текст, записать 1–3 секунды. | Образец появился в списке текущего профиля. Можно прослушать и удалить; автоматическая остановка через 8 секунд. |
| T13. Замер | Выбрать образец, нажать «Замерить», затем сравнить другую модель. | Текст, обработка в мс, длительность записи, RTF, подготовка отдельно. Нет реальных нажатий, в логе `sample.benchmark`. Это скорость готовой записи, не задержка живой команды. |
| T14. Реальный ввод | «Нажимать клавиши», курсор в собственном тестовом поле, произнести несколько повторов. | Поле получает по одному KeyQ на каждое выполненное короткое нажатие. Удержание может повторять символы, как физическая клавиша. |
| T15. Ручное удержание | Зажать Ctrl или целевую клавишу вручную и вызвать команду, затем отпустить. | Команда остаётся в очереди и выполняется после отпускания. Чтобы отменить её — «Остановить». |
| T16. Фразы | «Целая фраза»: сказать «первый день отпуска», когда назначено только «первый». | Нажатия нет. В режиме слов «первый» внутри этой реплики выполняется — это ожидаемо. |
| T17. Шапка | Прокрутить страницу до журнала. | Шапка с состоянием и кнопкой «Включить»/«Остановить» остаётся вверху. |
| T18. Несколько слов | В строке Q написать `ку, кью, пэ`, сохранить, включить. Сказать каждое слово. | Любое распознанное слово нажимает Q. Слово из другой строки — ошибка сохранения «повторяется». |
| T19. Запись голосом | Новая строка, клавиша T, кнопка 🎙, сказать слово три раза. «Добавить», «Сохранить». | В строке три услышанных варианта (одинаковые объединены). Во время записи клавиши не нажимаются. Занятые другой клавишей слова пропущены с сообщением. |
| T20. Записанный вариант | После T19 включить прослушивание и сказать то же слово как обычно. | Нажимается T, даже если уверенность Vosk низкая. Режим «Целая фраза» и «Каждое слово» работают оба. |
| T21. Модификатор | Включить Ctrl у строки Q, режим «Нажимать клавиши», поле проверки в фокусе, сказать слово. | Поле получает Ctrl+Q (код `KeyQ` с зажатым Ctrl); Ctrl отпущен после нажатия. В оверлее плитка «Ctrl+Q». |
| T22. Мышь и колесо | Назначить среднюю кнопку и «Колесо вниз» на слова, открыть страницу в браузере, сказать слова. | Клик средней кнопкой, прокрутка на одну зарубку на слово. «Колесо» всегда «Нажать». |
| T23. Журнал на лету | Сказать слово, которое модель не знает; в журнале выбрать команду и «Назначить». | Прослушивание не прерывается; то же слово теперь нажимает клавишу. |
| T24. Звук | «Звук, вид и трей» → «Проверить звук»; сказать команду. | Высокий сигнал при распознавании, низкий при нажатии. Громкость и включатели работают без перезапуска. |
| T25. Тема | Выбрать «Тёмная», затем «Как в Windows». | Окно переключается сразу; текст читается во всех блоках и диалогах. |
| T26. Трей | Закрыть окно крестиком; затем клик по значку; меню → профиль → «Выход». | Окно прячется, прослушивание идёт, значок зелёный. Клик возвращает окно. «Выход» завершает программу. |
| T27. Основной монитор | Окно Voice Keys на втором мониторе, «Показать пример». | Оверлей на основном мониторе Windows. |
| T28. Экспорт/импорт | Экспорт «Все профили», затем «Импорт» того же файла. | Появляются копии «Имя (2)»; текущий профиль не меняется. Посторонний `.json` отклоняется с сообщением. |
| T29. Задержка | Сказать несколько команд. | Под результатом три значения и среднее; в логе `latency` у `input.started`. |
| T30. GigaAM | «Модель» → «GigaAM v3», «Загрузить» (если нет), сохранить, включить; «первый второй третий» подряд в режиме слов. | Q, W, E по порядку; текст в «Модель слышит» появляется по ходу речи; задержка в блоке «Задержка». |
| T31. Сравнение | В «Образцах голоса» записать слово, «Замерить» на Vosk, T-one и GigaAM. | Видно текст, время обработки и RTF каждой модели на ваших словах. |

Для образцов полезны три повтора каждого слова: «первый», «хэви», затем фраза «первый первый второй». Нужны разные записи, не копии одной. Если английское queue распознаётся как pew, попробуйте другое различимое слово и назначьте ему ту же Q. Если модель не выдала нужное слово, приложение не может само восстановить пропущенное произнесение.

## Выполненные автоматические проверки

`run-tests.bat` / `npm test` запускает 86 проверок без микрофона и реального ввода: слова, повторы, изменения текста, очередь и интервалы, ручное удержание, отмена, профили и миграция, оверлей, локальный WAV, микрофоны, разрешения и логирование. Вывод — `data/tests-last.log`.

Интеграционный прогон 1.3 проверил настоящий Vosk на локальном синтезированном звуке, работу интерфейса, профили, остановку при переключении, оба направления оверлея, запись тестового микрофона и замер Vosk/T-one. Итог — `QA-1.3-RESULTS.json`. Настройки и записи тестов изолированы от пользовательских данных.

Дополнительный прогон реальных клавиш 1.3 не дошёл до отправки: Windows не подтвердила фокус собственного тестового окна. Защита остановила тест, статус — `QA-1.3-NATIVE.json`. Поэтому реальную очередь Q Q Q и оверлей поверх выбранной игры следует проверить по T03/T08/T14. Это ограничение окружения теста; его не считали успешным нативным прогоном.

## Что прислать при ошибке

Номер теста, время, профиль, язык, модель, режим команд и **что сказали → что модель показала → что ожидали → что произошло**. Приложите `.jsonl` запуска из «Папка логов ↗»; если окно не открылось — `data/startup.log`.

События: `recognition.partial/final`, `action.matched` (с номером повторения `occurrence`), `input.request/started/result`, `preview.request/result`, `profile.changed`, `sample.saved`, `sample.benchmark`. Аудио обычных команд не записывается. Образцы сохраняются по кнопке «Записать» в `data/samples`; они не отправляются автоматически.
