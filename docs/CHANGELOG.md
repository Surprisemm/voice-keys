# Журнал изменений

Номера 1.1–1.8 в старых заметках (`archive/changes-before-1.0/`), `MODELS.md` и `TESTS.md` — внутренние этапы разработки, а не выпущенные версии.

## Версия 1.0.1

Исправление зависания нажатий.

**Симптом.** Команды «первая, вторая, третья» распознаются (в окне видны), но клавиши не нажимаются; очередь стоит, пока не остановить прослушивание.

**Причина (по журналам установленной копии, `%APPDATA%\Voice Keys\logs`).** Оба случая (31.10 и 03.11) начинаются сразу после того, как системные часы Windows прыгнули на час назад (в журнале время идёт `21:46:31 → 20:46:32`). Очередь клавиш считала паузы по `Date.now()`. После нажатия клавиши она запоминает время её отпускания, и следующее нажатие той же клавиши ждёт «время отпускания + пауза». Когда часы откатились на час, это время оказалось на час впереди, и первая же команда в очереди ждала около часа; все остальные стояли за ней. В журнале это видно по записям `input.request` без `input.started`, которые отменяются только при остановке прослушивания.

**Исправление.** Все замеры интервалов теперь идут по монотонному счётчику (`monotonicNow` в `src/core.js`), на который смена системных часов не влияет: очередь клавиш (`src/key-controller.js`), окно сверки классификатора и текстового распознавания (`src/classifier/arbiter.js`), стабильность слова в `WordCommandMatcher`, время жизни записей оверлея, время приёма речи в `main.js`. Тот же откат часов оставлял в окне сверки устаревшие записи, а в матчере слова, которые «ждали» ещё час.

Проверка: `test/clock-jump.test.js` (откат часов на час не задерживает следующее нажатие, окно сверки истекает как обычно); старое поведение воспроизведено и давало зависание.

**Что не менялось.** Если вы физически держите Ctrl/Shift/Alt/Win или саму клавишу команды, команда по-прежнему ждёт отпускания (так задумано, чтобы не превратить «первый» в Ctrl+1).

**Действие «Переключить».** Команда зажимает клавишу и держит её, пока вы не скажете команду ещё раз или не нажмёте клавишу сами (программа замечает, что клавиша стала отпущенной). Остановка прослушивания кнопкой «Стоп», смена профиля и выход отпускают клавишу. Код: `src/key-controller.js`, проверка — `test/toggle.test.js`; на настоящем вводе проверено на безвредной клавише F24.

**Классификатор по шагам.** Панель разбита на пять шагов; шаги 2–5 закрыты, пока не установлены Python и PyTorch. Библиотека слов больше не заполняется словами профиля: слово вы вписываете и записываете сами (по умолчанию 30 повторений), а в команду любого профиля оно добавляется списком «Обученные слова» в строке команды. Сеть можно обучить **для профиля** (слова его команд, у которых есть записи) или **общую**; в профиле слушает его сеть, при её отсутствии — общая. Сети лежат в `classifier/models/` (старый `model.json` становится общей сетью). Код: `src/classifier/scopes.js`, `store.js`, `trainer.js` (`--words` в `tools/ml/train_classifier.py`), `ui/classifier.js`; проверки — `test/classifier-scopes.test.js` и PyTorch-тест в `test/classifier-store.test.js`.

**Панель классификатора переделана по шагам: Python → профиль → слова → фон → обучение.** Профиль выбирается в самой панели (это те же профили, что у команд) и можно добавить, дублировать, переименовать и удалить его. Профиль «Общий» есть всегда и не удаляется: он знает все записанные слова, его сеть общая. В новой установке только он (с командами Deadlock: 1–4, «хэви», «удар», «блок»). У остальных профилей свой набор слов (`neuralWords` в профиле) и своя сеть; слово из библиотеки добавляется в профиль без повторной записи. Слово можно записать ещё, перезаписать, убрать из профиля. Цвета: зелёное — записано полностью, жёлтое — недозаписано (8–29 повторений), красное — меньше 8, в обучении не участвует. Фон один на все профили. Кнопка «Обучить» недоступна для пустого профиля. Ниже — прежнее описание слов в командах.

**Запись на самой кнопке.** Вместо большого блока записи посередине страницы: при нажатии «Записать слово», «Записать ещё», «Перезаписать», «Записать фон» (и «Записать» в «Образцах голоса») кнопка заменяется счётчиком «3 из 30», полоской уровня микрофона и кнопкой ■, подсказка и причина отклонения записи стоят под ними; сообщения о результате показываются в том же шаге. Общий механизм — `inlineRecorder` в `ui/app.js`, его используют и будущие записи. Окно «Запись произношения» (🎙 у команды) осталось отдельным диалогом.

**Слова нейросети у каждой команды.** Под текстовым полем команды появился блок «Нейросеть»: слова из библиотеки классификатора горят плашками (зелёная — сеть обучена, красная — нет записей или сеть ещё не обучена на слове), у каждой есть × и список «＋ слово». Текстовое поле осталось для обычного распознавания; обе части работают независимо, команду выполняет тот, кто узнал её первым, второй раз она не нажимается. Старые настройки переносятся: однословные фразы, для которых есть записи, становятся словами нейросети. У профиля в строке профилей значок «Нейросеть обучена / устарела / не обучена», в разделе классификатора — «Профили и сети» (что нужно записать или переобучить), подсказка «i» с инструкцией и строка «Что дальше». Сеть помнит, на скольких записях каждого слова она обучена, и подсвечивает «устарела», когда записей стало больше.

**Модели распознавания скачиваются в приложении.** Ни одна модель больше не входит в установщик и в репозиторий. В «Настройки → Распознавание» таблица всех моделей (лицензия, автор, источник, размер, «Скачать» / «Выбрать»), а пока выбранная модель не скачана, вверху окна жёлтая полоса с кнопкой «Скачать» (ход загрузки показывается в строке под настройками; загрузка идёт через сетевой стек окна и учитывает прокси Windows). Пока модель не скачана, «Включить микрофон» подсказывает, что делать. Для разработки `npm run setup` по-прежнему скачивает модели в папку `models/`.

**Блок команд компактнее.** Строка команды стала заметно ниже: «＋» для слов нейросети рядом с микрофоном, плашки слов отдельной строкой только когда они есть; блок больше не ограничен по высоте. Убраны флажок «Оба языка» (показаны команды выбранного языка) и пояснение под командами: оно перенесено в подсказки кнопок.

**Структура репозитория.** Документы в `docs/`, служебные скрипты в `scripts/`, корень содержит только то, что нужно для запуска и сборки. Добавлены `LICENSE` (MIT), `.gitignore`, `README.en.md`.

**Профиль по умолчанию** (только новая установка и сброс повреждённых настроек): один «Общий» с командами Deadlock (1–4, «хэви» — удержание Q, «удар» — Q, «блок» — F). Код: `defaultStore` в `src/profiles.js`.

## Версия 1.0.0

Первый выпуск: установщик и portable (`npm run pack`). Номера 1.1–1.8 в старых заметках (`history/`), в `MODELS.md` и `TESTS.md` — внутренние этапы разработки, а не выпущенные версии.

- **Срабатывание по началу слова** (режим «Каждое слово отдельно»). Команда нажимается, когда начало произносимого слова подходит ровно одной команде («пес» → «песня», если других команд на «пес» нет). Если начало подходит нескольким («ле» для «лето» и «легко»), программа ждёт, пока слово не станет однозначным. Слово, которое одновременно полностью совпало с командой и является началом другой («лет» и «лето»), ждёт 150 мс или конца реплики. Варианты одного действия («ку, кью») не мешают друг другу. Настройка — флажок «Срабатывание по началу слова (3 буквы)» в настройках распознавания, по умолчанию включён; число букв не настраивается. Флажок хранится в профиле; если его снять, программа ждёт целое слово.
- Интервал опроса GigaAM 120 → 60 мс, стабилизация слова по умолчанию 0 мс (допустимо 0–500).
- Захват звука через AudioWorklet (блоки по 512 отсчётов), без эхоподавления, шумоподавления и автоусиления браузера.
- Профиль хранит только команды. Модель, язык, режимы, стабилизация, срабатывание по началу слова и остальные настройки общие для приложения. Старые файлы настроек переносятся: общими становятся настройки активного профиля, у остальных профилей остаются только команды. Файлы экспорта профилей содержат только команды; настройки из старых файлов при импорте игнорируются. Профиль, в котором нет команд на выбранном языке, можно выбрать (раньше переключение отклонялось).
- **Настройки сохраняются автоматически** через 0,7 с после последнего изменения; кнопки «Сохранить» убраны. Автосохранение не перерисовывает форму, не срабатывает во время прослушивания и показывает ошибку проверки в строке под настройками («Не сохранено: …»), пока строка исправлена не будет.
- **Новый вид:** мягкий минималистичный стиль, светлая тема в тёплых бежевых тонах, тёмная в тёплых тёмно-коричневых (вместо зеленоватых). Цвета — переменные в `ui/style.css`; генератор тёмной темы убран.
- Быстрый классификатор включён по умолчанию (если модель не обучена, приложение просто предупреждает и работает как раньше). Явно выключенный флажок сохраняется.
- **Установщик (NSIS)**: для всех пользователей в `C:\Program Files\Voice Keys`, перед копированием файлов страница «Ярлыки программы» (ярлык на рабочем столе, ярлык в меню «Пуск»); ярлыки создаются и удаляются установщиком (`build/installer.nsh`). Проверен прохождением мастера через UI Automation от администратора. В папке программы создаётся ярлык «Удалить Voice Keys»; деинсталлятор показывает страницу с флажком «Удалить данные» (по умолчанию снят; тихое удаление данных не трогает, кроме запуска с `--delete-app-data`). Есть и portable. Установленная версия хранит данные в `%APPDATA%\Voice Keys`, portable рядом с exe. Раздел «Данные и запуск»: путь к данным, открытие папки, перенос данных из другой папки, запуск вместе с Windows.
- Новая установка начинается с GigaAM.
- **Свой классификатор голоса:** запись команд и фона из интерфейса, обучение на PyTorch (видеокарта) либо встроенным способом, установка Python и PyTorch кнопкой. Движок: `src/classifier/`, обучение: `tools/ml/`. Флажок «Использовать быстрый классификатор» (общая настройка приложения, по умолчанию включён): классификатор работает в отдельном потоке рядом с обычным распознаванием, команда нажимается один раз тем, кто узнал её первым (`src/classifier/arbiter.js`).
- **Захват звука: Chromium или WASAPI** (настройка в распознавании, по умолчанию Chromium, общая для приложения). WASAPI — отдельная программа `native/WasapiCapture.exe` (`npm run native`), при ошибке запуска приложение возвращается к Chromium. Проверка на микрофоне — `compare-capture.bat`.
- Сравнение моделей и замеры — в `MODELS.md`.

Риск режима по началу слова: нажатие нельзя отозвать. Если после «пер» вы скажете не «первый», а «перо», клавиша уже нажата. На стенде при 3 буквах ложных срабатываний на посторонних словах нет; срабатывают только слова, которые модель сама слышит как команду («первое» → «первый»). При 2 буквах на стенде появилось одно лишнее срабатывание («лето» → «лечение»), поэтому порог закреплён на 3.
