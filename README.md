# Voice Keys

[English version](README.en.md)

Голосовой контроллер для Windows: вы говорите слово, программа нажимает клавишу (или зажимает, или переключает её). Сделан для игр, где руки заняты мышью и клавиатурой: Dota 2, Deadlock, iRacing и других. Работает локально, звук никуда не отправляется.

- **Три действия:** нажать, удержать на заданное время, переключить (клавиша зажата, пока вы не скажете команду ещё раз).
- **Профили** под разные игры. В новой установке один профиль «Общий» (его нельзя удалить; в нём команды Deadlock), остальные добавляете сами. Профиль хранит команды и слова нейросети; всё остальное (модель, язык, микрофон) общее.
- **Три модели распознавания** (скачиваются в приложении): GigaAM v3 (русский, самая точная), Vosk Small (русский и английский), T-one (русский).
- **Свой классификатор голоса:** маленькая нейросеть, обученная на ваших записях. Узнаёт команду по первому слогу, раньше обычного распознавания. Сеть можно обучить отдельно для каждого профиля или одну общую. Команду выполняет тот, кто узнал её первым.
- **Оверлей** с очередью нажатий поверх игры, быстрый захват звука через WASAPI, значок в трее, запуск вместе с Windows.

## Установка

1. Скачайте `Voice-Keys-Setup-<версия>.exe` из релизов и запустите. Программа ставится для всех пользователей в `C:\Program Files\Voice Keys` (Windows спросит разрешение администратора). Перед установкой мастер спрашивает, создавать ли ярлыки на рабочем столе и в меню «Пуск». В папке программы есть ярлык «Удалить Voice Keys»: деинсталлятор спрашивает, удалять ли данные.
2. Есть и один файл без установки: `Voice-Keys-<версия>-portable.exe`.
3. При первом запуске скачайте модель распознавания: вверху окна появится жёлтая полоса с кнопкой «Скачать», а в «Настройки → Распознавание» есть таблица всех моделей с лицензией, источником, размером и кнопками «Скачать» и «Выбрать». Нужен интернет один раз.
4. Выберите микрофон, нажмите «Включить микрофон» и говорите команды. «Только показать» — безопасный режим без нажатий, «Нажимать клавиши» — настоящий ввод.

Данные (настройки, профили, записи голоса, сети): установленная версия — `%APPDATA%\Voice Keys`, portable — папка `VoiceKeys-data` рядом с exe, запуск из исходников — `data/`.

Сборка не подписана: Windows SmartScreen может предупредить о неизвестном издателе («Подробнее» → «Выполнить в любом случае»).

## Запуск из исходников

Нужны Windows 10/11 x64 и Node.js 22+.

```bash
start.bat                 # установит зависимости и запустит программу
npm ci                    # или вручную
npm start
npm run setup             # скачать модели Vosk в models/ (для разработки)
npm test                  # проверки без микрофона и без нажатия клавиш
npm run pack              # собрать установщик и portable в release/
```

Для обучения классификатора нужны Python и PyTorch (около 2 ГБ с видеокартой NVIDIA, один раз): кнопка в разделе «Свой классификатор голоса» или `npm run setup-ml`.

## Устройство репозитория

| Папка | Что там |
|---|---|
| `src/` | основной процесс Electron: распознавание, очередь клавиш, классификатор, профили, данные |
| `ui/` | окно программы и оверлей |
| `native/` | помощник захвата звука WASAPI на C# (собирается при сборке) |
| `tools/ml/` | обучение сети на PyTorch |
| `scripts/` | сборка, установка моделей и окружения, служебные утилиты |
| `build/` | значок и сценарий установщика NSIS |
| `test/` | автоматические проверки |
| `docs/` | руководство, журнал изменений, сравнение моделей, архив |

Папки `models/`, `data/`, `release/`, `node_modules/` в репозиторий не попадают.
